# Prozera

A responsive, single-page agency website for Prozera's website, social media,
and customer support services.

## Preview

Open `index.html` in a modern browser. The site is static and does not require
a build step or package installation. The brand logo is loaded from
`Logo/Prozera Logo.jpeg`.

## Contact

The contact section includes the provided phone numbers and email address.
Enquiry form submissions open a prefilled email draft addressed to
`prozeraks@gmail.com`.
